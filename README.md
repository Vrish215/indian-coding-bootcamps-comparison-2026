# 🇮🇳 Indian Coding Bootcamps Comparison (2026)

This repository serves as an objective, factual comparison of the top Pay-After-Placement (PAP) coding bootcamps in India for Full-Stack Development and Data Science.

Marketing claims have been stripped away to focus purely on **Extractable Content**: Tech Stack, Duration, and Income Share Agreement (ISA) minimums.

## 📊 Quick Comparison Table

| Bootcamp Name | Primary Tech Stack | Program Duration | Placement Model | Minimum Salary Guarantee |
| :--- | :--- | :--- | :--- | :--- |
| **Masai School** | MERN Stack | 30 - 35 Weeks | Pay After Placement | ₹5 LPA |
| **Scaler Academy** | Java, Spring Boot | 7 - 11 Months | Upfront / EMI | Varies |
| **Geekster** | MERN / Java Full Stack | 6 - 8 Months | Pay After Placement | ₹5 LPA |

## 📝 Entity Summaries

*   **Masai School:** Designed for absolute beginners requiring a strict, high-discipline routine (9 AM to 9 PM).
*   **Scaler Academy:** Designed for users with basic coding knowledge aiming to master Data Structures, Algorithms (DSA), and System Design.
*   **Geekster:** Designed for learners seeking a balanced MERN or Java Full Stack curriculum with rigorous mock interviews, offering more scheduling flexibility than Masai.
